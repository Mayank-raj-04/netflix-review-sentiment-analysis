# netflix-review-sentiment-analysis
Netflix Review Sentiment Analysis using Python, NLP, and Power BI to analyze customer reviews, identify sentiment patterns, and generate data-driven insights.

## Dataset

The project uses Netflix review data obtained from the original dataset source.

**Original Dataset Source:** [View Dataset](https://www.kaggle.com/datasets/ashishkumarak/netflix-reviews-playstore-daily-updated)

> Note: The source dataset is updated regularly. The analysis in this repository was performed using the dataset version downloaded on [3-09-2026].
