# Netflix Review Sentiment Analysis

A data analytics project that analyzes Netflix user reviews using Python, Natural Language Processing (NLP), sentiment analysis, and Power BI to understand customer feedback, identify sentiment patterns, and generate data-driven insights.

---

## 📌 Project Overview

This project analyzes customer reviews related to the Netflix application, with a particular focus on understanding user sentiment and feedback.

The project combines Python-based data processing and sentiment analysis with processed datasets and an interactive Power BI dashboard to explore customer reviews and sentiment patterns.

The analysis includes review information such as ratings, review content, app versions, review dates, predicted sentiment scores and labels, subjectivity scores, and sentiment expected from ratings.

---

## 🎯 Project Objective

The main objective of this project is to analyze Netflix customer reviews and understand the sentiment expressed by users.

The project demonstrates an end-to-end data analytics workflow:

- Data collection
- Data processing
- Sentiment analysis
- Dataset preparation
- Data visualization
- Interactive dashboard development
- Data-driven interpretation

## 📊 Dataset

The project uses Netflix review data obtained from the original dataset source.

### Original Dataset Source

**[View Netflix Reviews Dataset on Kaggle](https://www.kaggle.com/datasets/ashishkumarak/netflix-reviews-playstore-daily-updated)**

> **Important:** The source dataset is updated regularly. The analysis in this repository was performed using the dataset version downloaded on **03-09-2026**. Therefore, the current dataset available at the source may contain newer data and may differ from the version used in this project.

---

## 🗂️ Data

The original dataset contains Netflix application review information such as:

- Review ID
- User name
- Review content
- Rating
- Thumbs-up count
- Review-created version
- Review date and time
- App version

The processed dataset contains additional sentiment-related fields, including:

- Period
- Predicted Sentiment Score
- Predicted Sentiment Label
- Subjectivity Score
- Expected From Rating

The processed analysis includes the **After Price Hike** review period.
