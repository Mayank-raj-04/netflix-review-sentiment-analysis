# Netflix Review Sentiment Analysis

A data analytics project that analyzes Netflix user reviews using Python, Natural Language Processing (NLP), sentiment analysis, and Power BI to identify sentiment patterns and generate data-driven insights.

## Project Overview

This project focuses on analyzing customer reviews related to Netflix to understand the sentiment expressed by users.

The project combines Python-based data processing and sentiment analysis with an interactive Power BI dashboard for visualization and analysis.

## Dataset

The project uses Netflix review data obtained from the original dataset source.

**Original Dataset Source:** [View Dataset](https://www.kaggle.com/datasets/ashishkumarak/netflix-reviews-playstore-daily-updated)

> **Note:** The source dataset is updated regularly. The analysis in this repository was performed using the dataset version downloaded on 03-09-2026.
